# Never Banned — Rust (read-only radar)

Atomic-style 2D radar + bone/box ESP. **No memory writes.**

Not included: aimbot, recoil control, chams, interactive camera, jump-shoot, spiderman, bright night/caves, instant eoka.

```
cd radar-web
python3 -m http.server 8765
```

Open `http://127.0.0.1:8765`. Demo world runs until DMA is hooked; Connect DMA is a status flag only.
